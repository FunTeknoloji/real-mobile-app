# FunID - Account Management Panel

FunID is a production-ready Flutter mobile application designed for secure and elegant account management.

## 🚀 Features

- **Supabase Integration**: Real-time authentication and profile management.
- **Dark Mode Design**: A deep purple aesthetic with neon green accents and glassmorphism.
- **Security Dashboard**: Monitor active sessions and security logs.
- **Family Management**: Group-based access control (mocked).
- **Smooth Animations**: Powered by `flutter_animate` for a premium feel.

## 🛠 Tech Stack

- **Framework**: Flutter
- **State Management**: Provider
- **Database/Auth**: Supabase
- **Navigation**: GoRouter
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (Inter)

## 📦 Getting Started

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```

## 🏗 Build Instructions

To build a release APK:
```bash
flutter build apk --release
```

## 🤖 CI/CD

This project uses GitHub Actions to automatically build and release APKs on every push to the `main` branch.
